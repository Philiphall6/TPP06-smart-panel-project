# Archives — démontage, NAND et UART / hardware recovery

[Guide débutant FR](../fr/DEMARRER-ICI.md) · [Beginner guide EN](../en/START-HERE.md)

Ces documents conservent l’historique du projet et les repères de récupération.
Ils **ne font plus partie du parcours normal d’installation**, qui commence
par l’accès réseau sans démontage. Les anciens numéros d’étapes et états de
validation décrivent les essais de l’époque, pas la situation actuelle.

These documents preserve project history and advanced recovery information.
They are **not normal installation steps**. Old phase numbers and validation
claims describe historical trials, not the current workflow. Original URLs
remain as redirects so existing links are not lost.

> [!WARNING]
> Panneau secteur : couper toutes les alimentations avant ouverture. Dessoudage,
> ressoudage et UART ne sont pas des opérations pour débutant. Ne jamais relier
> un PC à une carte potentiellement référencée au secteur ; faire intervenir
> une personne qualifiée. Un pont de soudure ou une tension incorrecte peut
> détruire définitivement la carte.
>
> Disconnect all power before opening a mains-powered panel. Soldering and UART
> recovery require qualified handling and a safely isolated setup. Never attach
> a PC to a potentially mains-referenced board.
