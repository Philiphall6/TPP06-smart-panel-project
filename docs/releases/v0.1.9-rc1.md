# v0.1.9-rc1 — Assistant ordinateur, référence après ADB et correctifs locaux

**Préversion expérimentale.** Pas un installateur universel ni une restauration
NAND garantie. La dernière release non-préversion reste disponible séparément.

## Nouveautés

- Assistant graphique Linux/Windows, édition **0.1.0-rc2**, avec lanceurs,
  dépendances Python, formulaires de confirmation et journaux privés.
- Parcours séparés : accès usine, ADB, sauvegarde, retour ciblé d’opération,
  mot de passe, logo, SSH Dropbear et préparation ESPHome seul. Premier reboot
  explicite et vérification de l’API chiffrée distincts.
- Référence souhaitée **après activation ADB** : le dump avant déblocage n’est
  plus obligatoire si la perte possible des personnalisations antérieures
  est explicitement acceptée.
- Acquisition de toutes les partitions NAND exposées par Linux, données et OOB,
  transferts par morceaux en RAM, deux lectures comparées et empreintes privées.
  Refus des blocs défectueux/erreurs ECC non pris en charge et des copies incomplètes.
- Politique ESPHome seul : pas de retour automatique à l’application Tuya,
  maintenance locale en cas d’échec et conservation des services réseau détenus.

## Correctifs

- Les commandes de diagnostic qui mentionnent Tuya ne sont plus confondues
  avec l’application Tuya active : évite le verrouillage indu des relais et du bip.
- Garde commune aux deux en-têtes d’identification de processus pour éviter
  les redéfinitions lors de la compilation ESPHome.
- Clavier Wi-Fi positionné explicitement dans la page ; paramètres organisés
  en liste verticale défilante. Outil de migration du raccourci Local inclus.
- YAML et composants épinglés ensemble au tag de cette préversion.

## Vérifications et limites

**332 tests passent** dans l’environnement ESPHome de vérification sur Mint,
avec les tests natifs et l’interface Tk activés. La suite propre à l’assistant
comprend **78 tests**. Aucun panneau n’a été modifié pour cette publication.

Les tests de l’assistant utilisent des fichiers, consoles, API et NAND simulés,
y compris les chemins d’échec. Ils ne prouvent pas une restauration physique.
Le parcours complet sur un panneau neuf et Windows réel reste à valider.

Deux lectures identiques ne prouvent pas la cohérence d’un système Linux actif.
Les zones NAND non exposées par Linux ne sont pas certifiées couvertes. Aucune
restauration NAND globale depuis le système actif n’est proposée : **ne pas
reflasher aveuglément les images et ne pas supprimer les anciens dumps**.
Le paquet de retour ADB n’est pas une sauvegarde complète de l’appareil.

Les correctifs de pilotes et d’interface ne constituent pas un nouvel essai
de bout en bout sur chaque variante. Ne pas compiler le firmware sur le panneau.
Compiler sa configuration privée dans ESPHome Device Builder / Home Assistant.
Une OTA d’interface ne remplace pas le superviseur Linux ni le logo NAND.

## Fichiers à télécharger

- **TPP06-Assistant-v0.1.0-rc2-sources.zip** : assistant seul, lançable avec
  Python et les dépendances documentées ; pas un EXE Windows autonome.
- **TPP06-HA-Panel-v0.1.9-rc1-sources.zip** : sources publiques complètes,
  modèles YAML, composants, scripts, tests et documentation.
- Les fichiers SHA-256 accompagnent les deux paquets.

Aucun firmware personnel, dump, mot de passe, clé Wi-Fi/API/SSH ni configuration
privée n’est distribué. Les outils binaires compatibles et le programme ARM
compilé dans HA sont fournis séparément par l’opérateur ; voir leurs empreintes
et prérequis dans le [guide de l’assistant](https://github.com/Philiphall6/TPP06-smart-panel-project/blob/v0.1.9-rc1/docs/fr/21-assistant-ordinateur.md).

## English summary

Experimental prerelease: desktop setup assistant with an explicit post-ADB
reference policy, exposed-NAND-partition acquisition, local-control detection
fixes, Wi-Fi keyboard positioning and scrollable settings. This is source code,
not a personal firmware or standalone Windows executable. Whole-chip coherent
backup/restoration and the complete fresh-device/Windows workflow remain
unvalidated. Do not erase existing backups or flash acquisition files blindly.
