# v0.1.0 — ADB par Wi-Fi sans UART (expérimental)

Première préversion de la méthode vérifiée sur un TPP06/AK3761E pour obtenir
un shell `root` par ADB sur le réseau, sans ouvrir le panneau.

## Contenu

- récupération en lecture seule de l'`AUTHKEY` et calcul du mot de passe root ;
- envoi de l'overlay par le protocole de production TCP `8090` ;
- démarrage persistant d'ADB sur TCP `5555` ;
- outil Python d'installation avec confirmation explicite ;
- paquet de retour arrière ;
- tutoriels français et anglais.

## Fichiers de la release

- `tpp06-adb-network-final.tar.gz` — overlay d'installation ;
- `tpp06-adb-rollback.tar.gz` — restauration du démarrage ADB d'origine ;
- `SHA256SUMS` — sommes de contrôle des deux archives.

## Compatibilité vérifiée

- produit : TPP06 / `ak3761e_tpp06z` ;
- SoC : Anyka AK3761E ;
- noyau : `4.4.192V2.4`, compilation du 13 décembre 2024 ;
- architecture : ARMv5TEJ.

Les autres révisions ne sont pas encore validées.

## Important

Le gestionnaire `bootpicture` remplace `/data/app` et `/data/customize`. Le
correctif du vieux démon ADB contourne aussi son vérificateur RSA défectueux :
tout client du LAN peut établir le transport ADB, même si le shell demande
toujours le compte `root` et son mot de passe. Ne jamais exposer `5555` ou
`8090` sur Internet.

Lire impérativement le [tutoriel complet](https://github.com/Philiphall6/TPP06-smart-panel-project/blob/v0.1.0/docs/fr/04-adb-wifi-sans-uart.md)
avant l'installation.

Merci à [t0m1o1](https://github.com/t0m1o1) pour TPPwned et la découverte de
l'extraction réseau de l'`AUTHKEY`, qui a rendu cette suite de travaux possible.
