# v0.1.9-rc2 — Projet ESPHome complet avec assistant 0.1.0-rc3

**Un seul paquet d’installation avec le dernier assistant.** Cette release
fournit l’assistant, ses scripts Linux nécessaires, le YAML ESPHome,
le logo Home Assistant public et les instructions. Elle est marquée **« Latest »**
sur GitHub, à la place de v0.1.8. Le tag et le code fonctionnel restent inchangés ;
le ZIP contient uniquement les fichiers d’installation, sans tests, photos,
sources des pilotes ESPHome ni archives historiques.
Ce changement de présentation ne certifie pas une stabilité ou une validation
matérielle supplémentaire : **les limites expérimentales ci-dessous restent applicables**.

## Quel fichier télécharger ?

**`TPP06-HA-Panel-v0.1.9-rc2-package.zip`** contient les fichiers utiles à
l’installation et à la configuration, y compris l’assistant **0.1.0-rc3**.
Télécharger aussi `TPP06-HA-Panel-v0.1.9-rc2-package-SHA256SUMS.txt` pour
contrôler son intégrité, puis extraire tout le dossier.

- Pour l’assistant : lire `README-assistant.md`, installer les dépendances sur
  le PC, puis ouvrir `Assistant-TPP06.cmd` (Windows) ou `Assistant-TPP06.sh` (Linux).
- Pour ESPHome : copier uniquement `esphome/tpp06-lvgl-complete.yaml` dans
  Device Builder et ajouter sa clé personnelle dans son `secrets.yaml` existant.
  Adapter ses propres entités et réglages. Les pages et pilotes sont téléchargés
  automatiquement depuis le tag GitHub indiqué par le YAML. Aucun dossier de
  composants ou de modules à copier dans HA. Compiler dans Device Builder,
  pas sur le panneau ni sur Mint ; Internet est requis au téléchargement initial.
- **L’assistant est déjà dans le paquet complet.** Cette release propose uniquement
  le ZIP complet et son fichier SHA-256, sans téléchargement séparé de l’assistant.

## Inclus dans cette version

- Un YAML qui importe les composants et fonctions ESPHome : relais/bip,
  clavier Wi-Fi, paramètres défilants, BLE et diagnostics. Les sources restent
  sur GitHub ; elles ne sont pas dupliquées dans le ZIP.
- Assistant FR/EN 0.1.0-rc3 : formulaires traduits, liens officiels Python/ADB,
  dossiers PC proposés et expliqués, préparation vérifiée des outils NAND/ADB.
- Logo Home Assistant bleu : aperçu PNG, image RGB565 320 × 480 / 512 Kio,
  empreintes, attribution et licence ; le SVG source reste dans le dépôt.
  **Le logo n’est pas un firmware OTA.**
- Instructions d’installation et scripts utilisés par l’assistant conservés
  dans le ZIP. Ces scripts Linux ne sont pas les pilotes externes ESPHome.
- Tests, photos du boîtier, archives matérielles, historiques de release et
  sources des pilotes/pages ESPHome et outils de développement conservés dans
  le dépôt GitHub, mais exclus du ZIP.
  Les liens vers ces documents sont redirigés vers le dépôt au tag de la version.

L’ancien asset `-sources.zip` est remplacé par `-package.zip`. Le contenu source
complet reste récupérable depuis le tag GitHub. Le nouveau paquet contient
`PACKAGE-CONTENTS.json` avec le commit source et les SHA-256 des fichiers.
Les fichiers de fonctionnement sont inchangés ; seul l’emballage et les liens
des guides diffèrent. Les photos n’ont pas été supprimées du dépôt.

Paquet allégé : 34 fichiers, 118 867 octets compressés. Les contrôles du paquet,
des empreintes et des liens passent ; le YAML seul a été validé avec les imports
GitHub réels. L’ouverture de l’assistant FR/EN extrait a été vérifiée sous Linux,
sans connexion au panneau. Aucun nouveau firmware ni essai matériel pour ce nettoyage.

Les modèles YAML et imports de composants sont épinglés ensemble sur
**v0.1.9-rc2**. Par rapport à rc1, cette release regroupe surtout le dernier
assistant : elle ne prétend pas ajouter de nouvelles fonctions au panneau.
L’assistant conserve sa version propre **0.1.0-rc3** à l’intérieur du projet.

## Vérifications et limites

**343 tests passent**, dont 89 tests de l’assistant. Validation des configurations
ESPHome et génération C++ sans compilation du firmware sur Mint ; tests
automatisés natifs et interface Tk sur Mint.
Les tests matériels de l’assistant sont simulés. Le parcours complet sur un
panneau neuf et Windows réel reste à valider : **version expérimentale**.

Ce sont des sources, pas un EXE Windows autonome ni un firmware universel prêt
à flasher. Aucun mot de passe, clé Wi-Fi/API/SSH, dump ou YAML personnel n’est
distribué. Dropbear nécessite encore sa préparation compatible documentée.

La copie NAND après ADB couvre les partitions exposées avec données/OOB et deux
passes comparées. Elle ne certifie ni la cohérence d’une copie à chaud ni une
restauration physique complète ; la restauration NAND globale n’est pas automatisée.
Conserver les sauvegardes privées existantes.

**Aucun panneau modifié pour cette publication.** Mettre à jour l’assistant PC
ne nécessite pas d’OTA. Pour un panneau déjà opérationnel, ne pas relancer la
première installation. Une OTA ne remplace ni le superviseur Linux ni le logo NAND.

## English summary

Complete experimental ESPHome project release including desktop assistant
0.1.0-rc3, now marked **Latest** on GitHub. The tag and runtime code are unchanged;
this label does not certify stability or additional hardware validation.
The lean `-package.zip` replaces the previous `-sources.zip` asset. Tests, photos,
historical documentation and maintainer utilities remain in Git, not in the ZIP.
Download the installation package for one YAML, the FR/EN assistant and its
required Linux scripts, the public boot logo and setup instructions. ESPHome
fetches drivers/pages directly from pinned GitHub sources; none are duplicated
in the ZIP. Copy only the YAML to Device Builder, provide your own secrets,
then build in Home Assistant. Initial downloads require Internet.
Only the complete ZIP and its SHA-256 file are provided; the assistant is already
included. YAML/component references are pinned
together to v0.1.9-rc2; panel functionality is unchanged from rc1.
Sources only, no personal data, universal firmware or standalone Windows EXE.
No device was modified. Complete fresh-device/Windows workflows and full NAND
restoration remain unvalidated. Updating the PC assistant does not require OTA.
