# v0.1.6 — Interface moderne et commandes locales / Modern UI and local controls

## Français

**Release de sources expérimentale**, pas un firmware universel prêt à flasher.
Matériel de référence : TPP06/AK3761E, Linux Anyka ARMv5, ESPHome 2026.10.2
et LVGL 9.5.0. Le numéro de cette release est `v0.1.6` ; le modèle conserve
l’identifiant du programme testé, **`0.1.6-glass.2-dev`**, pour ne pas prétendre
qu’un nouveau binaire a été recompilé et installé lors de la publication.

### Inclus

- Accueil sombre, cartes dégradées, météo HA, heure/date et navigation arrondie.
- Logo HA seul en haut à gauche : pulsation bleue avec client HA connecté,
  gris sinon. Petite horloge à droite près du Wi-Fi, sans doublon sous la météo.
- Bip tactile local corrigé, actif par défaut, désactivable et mémorisé.
- Trois boutons/relais/voyants locaux et entités HA ; le modèle public conserve
  l’observation par défaut avant validation des charges et du matériel.
- Stockage disponible/total, redémarrage de l’application et redémarrage Linux
  séparés, avec contrôles préalables.
- Éditeur Wi-Fi dans les paramètres : scan, sélection, mot de passe masqué,
  essai borné et confirmation/annulation ; service Linux optionnel distinct de l’OTA.
- Guides FR/EN actualisés, photos du boîtier conservées, récupération matérielle
  archivée. Les README renvoient désormais à la dernière release.
- Pilotes et import du modèle actuel épinglés au tag `v0.1.6`.

### Vérifié et limites

- Programme de référence compilé dans HA ; capture réelle du nouvel accueil.
  Contrôle en lecture seule avant publication : version attendue, binaire
  identique à l’artefact compilé, API chiffrée et superviseur sain.
- Météo et bip confirmés par le propriétaire ; boutons/relais/voyants déjà validés.
- **185 tests automatisés réussis, aucun ignoré** : schéma/code généré, pilotes avec appels système
  simulés, supervision, transactions Wi-Fi et documentation. Ils ne remplacent
  pas les essais physiques.
- Service Wi-Fi vérifié **au repos seulement**. Migration réelle, retour arrière
  réseau, remplacement d’une box absente et démarrage sans réseau non validés.
- Veille/réveil, coupures secteur, comportement des relais après panne, modes
  impulsion et boutons de redémarrage nécessitent encore des essais réels.
- Le logo NAND est distinct ; sa relecture a été contrôlée, pas sa couleur
  lors d’un démarrage à froid. L’OTA de cette interface ne le modifie pas.
- Le secours vise Tuya d’origine, pas le précédent programme ESPHome. Il ne
  couvre pas une panne NAND/noyau. L’assistant d’installation n’est pas validé
  de bout en bout pour un novice sans accompagnement.

### Installer / mettre à jour

Télécharger les sources de **ce tag**, puis suivre le
[guide débutant](https://github.com/Philiphall6/TPP06-smart-panel-project/blob/v0.1.6/docs/fr/DEMARRER-ICI.md).
Utiliser `esphome/tpp06-lvgl-modern.yaml`, garder vos identifiants et clés,
adapter les entités et compiler dans Device Builder sur HA. Pour un panneau
déjà sous ESPHome, vérifier sauvegarde et espace OTA puis effectuer un seul
envoi sans fil. Ne pas réinstaller le superviseur ni changer le Wi-Fi pour
une mise à jour graphique. Première installation : procédure accompagnée.

**Aucun secret, dump, capture privée ou programme personnel joint.** Les
archives automatiques de GitHub contiennent les sources publiques. Chaque
installation doit produire son propre programme avec ses clés privées.

## English

**Experimental source release**, not a universal precompiled firmware.
Reference target: TPP06/AK3761E, Anyka ARMv5 Linux, ESPHome 2026.10.2 and
LVGL 9.5.0. Repository release `v0.1.6` deliberately retains the tested
application identifier **`0.1.6-glass.2-dev`**; publication does not imply
a new firmware rebuild or installation.

Includes the dark weather dashboard, animated blue/grey HA logo, top-right
clock/Wi-Fi, local remembered touch beep, local relay integration, storage
summary, separate guarded application/Linux restart buttons, and an optional
Linux-backed on-screen Wi-Fi editor. Current template drivers/import are
pinned to this tag. FR/EN guides and enclosure pictures are retained; READMEs
link to the latest release instead of interface generation labels.

The reference build compiled in HA; a live capture showed the new home page.
Read-only pre-publication checks confirmed the installed build identity,
matching executable, encrypted API and healthy supervisor. Weather/beep and
physical relays/indicators were owner-confirmed. **185 offline tests passed,
none skipped**, covering
schemas, generated code, native drivers with fake syscalls, supervisor/Wi-Fi
transactions and documentation; these are not physical fault tests.

Wi-Fi service validation is **idle-only**: actual migration, network rollback,
replacement of an absent router and offline cold boot remain unvalidated.
Sleep/wake, power loss, relay recovery, inching and restart buttons still need
hardware trials. NAND boot-logo replacement is separate and not performed by
UI OTA. Its readback was checked, not its colour at cold boot. Fallback returns
to stock Tuya, not automatically to the previous ESPHome program, and cannot
recover kernel/NAND failures. First commissioning still needs assistance.

Use this tag’s sources and the
[beginner guide](https://github.com/Philiphall6/TPP06-smart-panel-project/blob/v0.1.6/docs/en/START-HERE.md).
Customise `esphome/tpp06-lvgl-modern.yaml`, retain private identity/keys, build
in HA, check backups/free OTA space and send one wireless update. UI OTA does
not require reinstalling the supervisor or changing Wi-Fi.

**Sources only: no personal executable, key, dump or private screenshot.**
Build privately for each installation. GitHub provides automatic source archives.
